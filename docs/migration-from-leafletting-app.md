# Migration from `leafletting-app`

`restore-swansea` was created as the clean successor to `ChrisHeard/leafletting-app`.

## Why this migration happened

The migration to this repository was done to avoid carrying forward damaged branch/version history from the old repository.

## Ongoing development

- Active development should continue in `ChrisHeard/restore-swansea`.
- `ChrisHeard/leafletting-app` should be treated as retired/historical.

## Baseline version

The initial version baseline for this repository is **v0.1.0**.
